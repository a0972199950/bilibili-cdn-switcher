這個功能主要要實現以下目標

1. 對 UI 介面進行重構
2. 增加對直播的支持

- 主頁右上角改成一個齒輪圖案，點擊後進入進階設定頁。並將失敗自動切換與顯示 debug 等開關移到進階設定。預設開關設定不變
- 主頁標題改為擴充在該語系的正式名稱
- 原本放在右上角的5星鼓勵換成一個和`問題回報`相似設計的金色按鈕，移到`問題回報`上面
- 將啟用以下的部分，分成兩個 tab `影片` 與 `直播`

## 影片
除了 `清單選擇` 與 `自行輸入` 以外，在最後面新增一個 `關閉`。這個關閉不同於最上面的 `啟用` 只作用於一般影片，效果是 `不介入一般影片的 CDN 選線，維持官方原始邏輯`。預設還是勾選 `清單選擇`

## 直播
- 先參照研究報告: research\live-streaming-support\README.md 了解原理
- 直播只有 `清單選擇` 與 `關閉` 兩個選項。關閉效果同上，但只作用於直播。預設勾選 `清單選擇`
- 直播的清單只有四個能選擇。預設不顯示具體 cdn 網址，只有當下為直播頁面，並且正在播放，能確定 CDN 網址時才顯示。預設選取 `國際線路(ov)`
  - 國際線路(ov)
  - 國際備用線路(b)
  - 中國線路(cn)
  - 中國備用線路(cn-b)
- 進入直播時，如果沒有該線路，則在標題後面加上備註 `當前直播沒有此線路`，並 disable，但不禁止使用者選擇

- 直播一樣可以測速，並有自己的測速頁。測速頁邏輯基本同 `影片` (例如只有當下為直播網址才可以測速、顯示標題等等...)
- 測速時，按照研究報告方式，測試兩個東西
  - 啟播速度(文案為 `切台卡頓`)，按照研究報告取三次平均值，測量結果顯示卡頓時間的毫秒數，備註高/中/低，並用紅黃綠字體表示
  0-800ms 為低；800-1500為中；超過1500為高
  - 是否能跟上直播(文案為 `持續觀看`)，每個節點測試8秒。完全跟上顯示綠字`優秀`；掉隊1秒內為黃字`中等`；掉隊超過一秒為紅字`差勁`

- 直播測速開始之前，要先檢查四個節點是否都存在。對於不存在的節點，該選項 disable並備註 `當前直播沒有此線路`，不做測試。但同樣不禁止使用者選擇
- `失敗自動切換` 功能在直播功能中，首先檢查使用者的節點是否存在，如果不存在，直接切回預設 `國際線路(ov)`。接下來則同一般影片檢測方式，持續一定時間沒有碼流，就切成 `國際線路(ov)`。這個切換一樣是針對當下特定直播做的 fallback，不影響使用者長期選擇線路


完成後自行尋找不同格式的直播房間，每種測試兩個
