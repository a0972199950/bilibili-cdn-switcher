# TW/SG 影片加速 for bilibili（非官方）— Microsoft Edge 商店介紹文字

## 簡短描述

讓台灣 / 新加坡使用者在網頁版 bilibili 上更順暢觀看 4K 等高畫質影片，減少緩衝與卡頓。非官方第三方擴充，與 bilibili 官方無關聯。

## 詳細描述

【本擴充為第三方個人開發，與 bilibili 官方無任何關聯，亦未獲其授權或背書。】

專為台灣、新加坡地區使用者優化的網頁版 bilibili 播放體驗改善工具。

海外使用者觀看網頁版 B 站時，影片常出現載入慢、緩沖頻繁、切換畫質卡頓等情形。
本擴充讓瀏覽器改用對台灣／新加坡連線品質較好的串流線路，減少緩沖等待，
使 4K 等高畫質影片播放更為順暢。

■ 主要功能
・開箱即用 —— 安裝後預設已套用對台／星最佳化的線路，無須設定
・多線路可選 —— 提供阿里雲、騰訊雲、華為雲、Akamai 等多組線路供自行比較切換，其他地區使用者也能挑選較近的線路
・自訂線路 —— 可自行輸入指定線路位址
・失敗自動切換 —— 偵測到線路請求失敗或播放卡住，先靜默切換到 B 站原生備援節點，備援也不行才會詢問你是否切換
・各節點測速 —— 獨立頁面即時測試目前影片、目前畫質下各線路的下載速度，方便自行比較
・即時狀態顯示 —— 播放器左上角可顯示目前實際使用的線路，方便比較效果
・多語系介面 —— 依瀏覽器語言自動切換繁體中文／簡體中文／English
・一鍵關閉 —— 關閉後完全不介入，恢復瀏覽器原本行為

■ 使用方式
安裝後開啟任一 B 站影片頁即自動生效。點擊工具列圖示可調整線路或關閉功能。

■ 隱私說明
本擴充不收集、不傳送任何使用者資料，無任何對外連線，也不含遠端程式碼。
所有設定僅儲存在你自己的瀏覽器中。程式碼完全開源，歡迎檢視。

■ 系統需求
Microsoft Edge 111 以上版本。
