# TW/SG 视频加速 for bilibili（非官方）— Chrome 商店介绍文字

## 简短描述

让台湾 / 新加坡使用者在网页版 bilibili 上更顺畅观看 4K 等高画质视频，减少缓冲与卡顿。非官方第三方扩充，与 bilibili 官方无关联。

## 详细描述

【本扩充为第三方个人开发，与 bilibili 官方无任何关联，亦未获其授权或背书。】

专为台湾、新加坡地区用户优化的网页版 bilibili 播放体验改善工具。

海外用户观看网页版 B 站时，视频常出现加载慢、缓冲频繁、切换画质卡顿等情况。
本扩充让浏览器改用对台湾／新加坡连接质量较好的流媒体线路，减少缓冲等待，
使 4K 等高画质视频播放更加顺畅。

■ 主要功能
・开箱即用 —— 安装后默认已套用对台/星最佳化的线路，无需设置
・多线路可选 —— 提供阿里云、腾讯云、华为云、Akamai 等多组线路供自行比较切换，其他地区用户也能挑选较近的线路
・自定义线路 —— 可自行输入指定线路地址
・失败自动切换 —— 检测到线路请求失败或播放卡住，先静默切换到 B 站原生备援节点，备援也不行才会询问你是否切换
・各节点测速 —— 独立页面实时测试当前视频、当前画质下各线路的下载速度，方便自行比较
・实时状态显示 —— 播放器左上角可显示当前实际使用的线路，方便比较效果
・多语言界面 —— 依据浏览器语言自动切换繁體中文／简体中文／English
・一键关闭 —— 关闭后完全不介入，恢复浏览器原本行为

■ 使用方式
安装后打开任一 B 站视频页即自动生效。点击工具栏图标可调整线路或关闭功能。

■ 隐私说明
本扩充不收集、不传送任何用户数据，无任何对外连接，也不含远程代码。
所有设置仅保存在你自己的浏览器中。代码完全开源，欢迎查看。

■ 系统需求
Chrome 111 及以上版本。
