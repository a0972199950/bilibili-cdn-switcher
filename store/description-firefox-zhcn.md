# TW/SG 视频加速 for bilibili（非官方）— Firefox 商店介绍文字

## 简短描述

在网页版 bilibili 看视频还在转圈等缓冲？自动换成对台湾／新加坡最快的线路，连 4K 都流畅播。免费、免设置。非官方第三方扩展，与 bilibili 官方无关联。

## 详细描述

你是不是也花钱开了 bilibili 大会员，结果全在转圈缓冲，钱全部打水漂？

这件事困扰我很久，直到最近终于找到真正有用的解决办法

于是我决定把这个解决办法做成浏览器扩展。相信还有很多人和我有一样的问题，希望它也能帮到你！

🆓 本扩展完全免费，并保证 "永远免费"!
⚡ 不需要任何设置，装好就自动生效!

装好之后随便打开一个 B 站视频，它就会在背后把线路换成对台湾／新加坡最快的那一条。加载更快、缓冲更少，连 4K 都能一路流畅播完。

■ 主要功能
・开箱即用 —— 安装后默认已启用对台/星优化的线路，无需设置
・多线路可选 —— 提供阿里云、腾讯云、华为云、Akamai 等多组线路供自行比较切换，其他地区用户也能挑选较近的线路
・自定义线路 —— 可自行输入指定线路地址
・失败自动切换 —— 检测到线路请求失败或播放卡住，先静默切换到 B 站原生备用节点，备用也不行才会询问你是否切换
・各节点测速 —— 独立页面实时测试当前视频、当前画质下各线路的下载速度，方便自行比较
・实时状态显示 —— 播放器左上角可显示当前实际使用的线路，方便比较效果
・多语言界面 —— 依据浏览器语言自动切换繁體中文／简体中文／English
・一键关闭 —— 关闭后完全不介入，恢复浏览器原有行为

■ 使用方式
安装后打开任一 B 站视频页即自动生效。点击工具栏图标可调整线路或关闭功能。

■ 隐私说明
本扩展不收集、不上传任何用户数据，无任何对外连接，也不含远程代码。
所有设置仅保存在你自己的浏览器中。代码完全开源，欢迎查看。

■ 系统需求
Firefox 140 及以上版本（Android 版需 142 及以上版本）。
