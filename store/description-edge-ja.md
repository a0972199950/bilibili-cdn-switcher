# 海外動画加速 for bilibili — Microsoft Edge アドオン 掲載用紹介文

## 簡単な説明

海外からでも Web 版 bilibili で 4K などの高画質動画をスムーズに再生し、バッファリングやカクつきを減らします。非公式のサードパーティ製拡張機能で、bilibili 公式とは関係ありません。

## 詳細な説明
（同じ機能の Tampermonkey／Greasemonkey スクリプトを入れている場合は、競合を避けるため先に削除してください）

bilibili の大会員（プレミアム会員）にお金を払ったのに、ずっと読み込み中のマークを眺めている……そんな経験はありませんか？

この問題にずっと悩まされてきましたが、ようやく本当に効く解決策を見つけました。

そこで、この解決策をブラウザ拡張機能にすることにしました。同じ悩みを抱えている人はきっとたくさんいるはず。あなたの役にも立てばうれしいです！

🆓 本拡張機能は完全無料。これからも「ずっと無料」をお約束します！
⚡ 設定は一切不要。インストールするだけで自動的に有効になります！

インストール後に bilibili の動画を開くと、お住まいの地域で実測して速かった回線へ裏側で自動的に切り替えます。読み込みが速くなり、バッファリングが減り、4K でも最後までスムーズに再生できます。

2.0.0 大型アップデート記念!!

■ 主な機能
・すぐに使える —— インストール後の設定は不要、自動的に有効になります
・全世界に対応 —— 台湾／シンガポールから、すべての国への対応に拡大！リストにない国でも「カスタムノードリスト」で利用できます
・実測で選んだノード —— 掲載中の国は、実際に人の手でテストして最速のノードを選定。ほかの国も順次追加中です……リストにない国でも「カスタムノードリスト」で利用できます
・ライブ配信に対応 —— 2.0 の新機能！ライブ配信でも国際回線／中国回線とそれぞれの予備回線を切り替えられ、回線が不調なときは自動で国際回線に戻ります
・CDN ノードを大幅拡充 —— Alibaba Cloud、Tencent Cloud、Huawei Cloud、Akamai など約 300 ノードを収録
・カスタムノードリスト —— 自分で指定したノードを複数追加でき、速度テストと並べ替えにも対応。公式の速度テストツール CDNSpeedTest（Windows）と組み合わせれば、あなたに最適なノードを見つけて自動で追加できます
・失敗時に自動切り替え —— 回線のリクエスト失敗や再生の停止を検出すると、まず bilibili 標準のバックアップノードへ自動で切り替え、それでもだめな場合にだけ切り替えるかどうかを確認します
・ノードごとの速度テスト —— 動画とライブそれぞれに専用のテスト画面があり、各ノード／回線の速度をリアルタイムで比較。上位 3 位には王冠を表示します。いつでも停止でき、テストの上限も調整可能。結果に合わせてノードを自動で並べ替えることもできます
・最速ノードへ自動切り替え —— オプション機能（既定はオフ）。動画ごとにバックグラウンドで速度をテストし、最速のノードへ自動で切り替えます
・状態をリアルタイム表示 —— プレーヤーの左上に、実際に使われている回線を表示でき、効果を比べるのに便利です
・多言語対応 —— ブラウザの言語に合わせて繁體中文／简体中文／English／日本語／한국어 を自動で切り替えます
・ワンクリックでオフ —— オフにすると一切介入せず、ブラウザ本来の動作に戻ります。動画とライブは個別にオフにすることもできます

■ 使い方
インストール後、bilibili の動画ページを開くだけで自動的に有効になります。ツールバーのアイコンをクリックすると、回線の変更や機能のオフができます。

■ プライバシー
本拡張機能はユーザーデータを一切収集・送信せず、外部への通信も行わず、リモートコードも含みません。
設定はすべてお使いのブラウザ内にのみ保存されます。ソースコードは完全にオープンソースです。ぜひご確認ください。
