# 해외 영상 가속 for bilibili — Firefox 부가 기능 소개 문구

## 간단한 설명

해외에서도 웹 bilibili에서 4K 등 고화질 영상을 더 매끄럽게 재생하고 버퍼링과 끊김을 줄여 줍니다. 비공식 서드파티 확장 프로그램이며 bilibili 공식과 관련이 없습니다.

## 자세한 설명
(같은 기능의 Tampermonkey/Greasemonkey 스크립트를 설치했다면 충돌을 막기 위해 먼저 삭제해 주세요.)

bilibili 대회원(프리미엄 멤버십)에 돈을 냈는데, 정작 로딩 표시만 보고 있지는 않나요?

저도 이 문제로 오랫동안 고생하다가, 마침내 정말 효과 있는 해결책을 찾았습니다.

그래서 이 해결책을 브라우저 확장 프로그램으로 만들기로 했습니다. 같은 문제를 겪는 분이 많을 테니, 여러분에게도 도움이 되면 좋겠습니다!

🆓 이 확장 프로그램은 완전 무료이며, '앞으로도 계속 무료'임을 약속합니다!
⚡ 설정은 필요 없습니다. 설치만 하면 바로 적용됩니다!

설치 후 bilibili 영상을 아무거나 열면, 내 지역에서 실측해 더 빨랐던 회선으로 뒤에서 자동 전환합니다. 로딩은 빨라지고 버퍼링은 줄어들어 4K도 끝까지 매끄럽게 재생됩니다.

2.0.0 대규모 업데이트 기념!!

■ 주요 기능
・바로 사용 —— 설치 후 별도 설정 없이 자동으로 적용
・가장 빠른 노드 자동 선택 —— 2.2 신규! 설치 후 또는 국가 변경 후 첫 영상에서 백그라운드 속도 테스트를 한 번 실행해 가장 빠른 노드로 바꿉니다(건너뛰기 가능)
・전 세계 지원 —— 대만/싱가포르에서 모든 국가 지원으로 확대! 목록에 없는 국가도 '사용자 지정 노드 목록'으로 사용할 수 있습니다
・직접 실측한 노드 —— 목록에 있는 국가는 사람이 직접 테스트해 가장 빠른 노드를 선정했으며, 다른 국가도 순차적으로 추가 중입니다… 목록에 없는 국가도 '사용자 지정 노드 목록'으로 사용할 수 있습니다
・라이브 지원 —— 2.0 신기능! 라이브 방송에서도 국제 회선/중국 회선과 각각의 예비 회선 사이를 전환할 수 있으며, 회선 상태가 나쁘면 자동으로 국제 회선으로 돌아갑니다
・CDN 노드 대폭 확대 —— 알리바바 클라우드, 텐센트 클라우드, 화웨이 클라우드, Akamai 등 약 300개 노드 수록
・사용자 지정 노드 목록 —— 직접 지정한 노드를 여러 개 추가할 수 있고, 속도 테스트와 정렬도 지원합니다. 공식 속도 테스트 도구 CDNSpeedTest(Windows)와 함께 쓰면 나에게 가장 빠른 노드를 찾아 자동으로 추가할 수 있습니다
・실패 시 자동 전환 —— 회선 요청 실패나 재생 멈춤을 감지하면 먼저 bilibili 기본 백업 노드로 조용히 전환하고, 백업도 안 될 때만 전환할지 물어봅니다
・노드별 속도 테스트 —— 영상과 라이브에 각각 전용 테스트 화면이 있어 노드/회선별 속도를 실시간으로 비교하고, 상위 3위에는 왕관을 표시합니다. 언제든 중지할 수 있고 테스트 한도도 조절할 수 있으며, 결과에 따라 노드를 자동 정렬할 수도 있습니다
・가장 빠른 노드로 자동 전환 —— 선택 기능(기본값 끔). 영상마다 백그라운드에서 속도를 테스트해 가장 빠른 노드로 자동 전환합니다
・실시간 상태 표시 —— 플레이어 왼쪽 위에 실제로 사용 중인 회선을 표시해 효과를 비교하기 편리합니다
・다국어 인터페이스 —— 브라우저 언어에 따라 繁體中文/简体中文/English/日本語/한국어를 자동 전환
・라이트/다크 테마 —— 2.1 신규! 고급 설정에서 시스템 설정 따름/라이트/다크 중에서 선택
・원클릭 끄기 —— 끄면 전혀 개입하지 않고 브라우저 기본 동작으로 돌아갑니다. 영상과 라이브를 각각 끌 수도 있습니다

■ 사용 방법
설치 후 bilibili 영상 페이지를 열기만 하면 자동으로 적용됩니다. 도구 모음의 아이콘을 클릭해 회선을 바꾸거나 기능을 끌 수 있습니다.
